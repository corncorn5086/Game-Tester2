# Ember Japanese typography

These offline WOFF2 subsets are generated from the corresponding Google Fonts
sources and include the glyphs used by the standalone Ember interface:

- Shippori Mincho Medium — editorial display and large titles
- Yuji Syuku Regular — calligraphic accents, seals and vertical phrases
- Zen Kaku Gothic New Medium — interface copy and Japanese labels

Each family is distributed under the SIL Open Font License. The unmodified
license text for every family is kept in `licenses/`.
