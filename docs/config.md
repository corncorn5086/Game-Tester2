# `ember.config.json` reference

Generated by `ember init`, validated by `ember config validate` and the desktop app.

## Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `configVersion` | number | – | Config format version (currently `1`) |
| `projectName` | string | ✔ | Human-readable project name |
| `engine` | string | ✔ | `unity` \| `unreal` \| `godot` \| `web` \| `custom` |
| `gamePath` | string | – | Project root relative to the config file (default `.`) |
| `buildCommand` | string | – | Command that builds the game |
| `launchCommand` | string | – | Command that launches the game |
| `testCommand` | string | – | Command that runs your engine test suite |
| `logsPath` | string | – | Folder **or single file** of game logs |
| `screenshotsPath` | string | – | Where captures are stored |
| `crashReportsPath` | string | – | Crash dumps folder — any file there raises a critical signal |
| `sourcePaths` | string[] | – | Folders included in code analysis (engine defaults) |
| `ignorePaths` | string[] | – | Folders excluded from scans (`node_modules`, `Library`, …) |
| `includeExtensions` | string[] | – | Extensions to analyze (engine defaults) |
| `excludeExtensions` | string[] | – | Extensions to skip |
| `maxFiles` | number | – | Scan cap (default 5000) |
| `testProfiles` | object | – | Named profiles: `{ "smoke": { "description", "checks": [], "commands": [] } }` |
| `customRules` | array | – | Your own analysis rules (below) |
| `backend` | object | – | `{ "url", "projectId", "token" }` — prefer `EMBER_AGENT_TOKEN` env over inline tokens |

## Checks available in `testProfiles[].checks`

Run today with config only: `scan`, `analyze`, `logs`, `build`, `test`, `launch`,
`custom-command`, `regression`.

Require a future engine SDK (reported as blocked until then): `navigation-menu`,
`controller-input`, `keyboard-input`, `collision`, `save-load`, `ui-flow`,
`combat-loop`, `inventory`, `quest-logic`, `performance`, `input-fuzzing`,
`scripted-scenario`.

## Custom rules

```json
"customRules": [
  {
    "id": "no-instant-respawn",
    "pattern": "Respawn\\(0\\)",
    "flags": "i",
    "message": "Instant respawn bypasses the death animation state machine",
    "severity": "medium",
    "category": "gameplay",
    "extensions": [".cs"]
  }
]
```

- `pattern` is a JavaScript regex applied per line.
- `severity`: `critical` | `high` | `medium` | `low`
- `category`: `crash` | `gameplay` | `ui` | `visual` | `performance` | `audio` | `save-system` | `input` | `network` | `build`
- Invalid regexes are reported by `ember config validate`.
